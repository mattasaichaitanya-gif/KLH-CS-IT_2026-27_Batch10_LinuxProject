Deadlock-Free 6-Step Hierarchy

Semaphore wait is called before mutex lock. Threads never sleep while holding the mutex, ensuring deadlocks are mathematically impossible.

Producer
  1. sem_wait(&empty)
  2. pthread_mutex_lock(&mutex)
  3. buffer_enqueue(item)
  4. pthread_mutex_unlock(&mutex)
  5. sem_post(&full)
Consumer
  1. sem_wait(&full)
  2. pthread_mutex_lock(&mutex)
  3. buffer_dequeue(&item)
  4. pthread_mutex_unlock(&mutex)
  5. sem_post(&empty)
